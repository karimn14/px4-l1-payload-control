# Gazebo Payload Assets

This directory contains the payload SDF models used for the ROS 2/PX4 SITL campaigns, plus the pickup, single-drop, multi-drop, and payload-wind world files for Gazebo Harmonic.

Payload variants are grouped under `models/` by mass. Scenario worlds are in `worlds/`. They use standard PX4 Gazebo model and plugin assets from the PX4 checkout.
