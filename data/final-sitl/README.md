# Final PX4 SITL Results

This directory contains the final quantitative results produced by the PX4 Software-in-the-Loop campaign using the ROS 2 offboard workflow and Gazebo Harmonic. MATLAB was used earlier for plant modeling, controller design, sensitivity analysis, and parameter tuning; the reported SITL comparisons in these files come from the PX4/ROS 2/Gazebo validation stage.

The tables are organized by scenario and controller. `metrics*_MASTER.csv` files consolidate repeated runs; dated `metrics*.csv` files retain per-run analysis. Selected comparison plots are in `figures/`.

The full raw time-series campaign files remain in the local research archive and are not part of this portfolio snapshot. This curated set preserves the final analysis tables and representative plots while keeping the repository focused.
